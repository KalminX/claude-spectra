## 4. Technical Coaching Curriculum & Optimization Blueprint

### Session 1: Environment & Tooling Audit (The Foundation)
- **Windows / WSL2 Architecture:** Benchmarking native Windows vs. WSL2 (Ubuntu) performance for Claude Code (I/O speed, file watchers, shell tooling).
- **Terminal & Shell Mastery:** Windows Terminal profiles, Zsh/Bash aliases, Oh My Posh / Starship prompt tuning, fuzzy search (`fzf`), and fast file navigation tools (`ripgrep`, `fd`).
- **Environment & Key Management:** Secure API key storage, session persistence, and config management across projects.

### Session 2: Claude Code Mastery & Advanced Configuration
- **Configuration & Rules Engine:** Setting up `.claude` configs, custom system prompts, project-specific instruction files (`CLAUDE.md`), and workspace rules.
- **Context & Token Optimization:** Mastering context hygiene, token budgets, selective file injection, and knowing when to reset vs. carry context.
- **Custom Tooling & Slash Commands:** Building reusable custom workflows, prompt templates, and execution shortcuts.

### Session 3: Model Context Protocol (MCP) & Tool Calling Expansion
- **MCP Server Ecosystem:** Installing, configuring, and debugging local MCP servers on Windows (Filesystem, PostgreSQL/SQLite, Git, Browser automation, Fetch).
- **Custom MCP Integration:** Building custom Python/TypeScript MCP tools tailored to the client's specific daily coding stack.

### Session 4: Agentic Coding Patterns & Multi-Step Workflows
- **Autonomous Refactoring & Debugging:** Driving Claude Code through complex test-driven development (TDD), large-scale code refactors, and multi-file architecture changes.
- **Subagents & Parallel Execution:** Coordinating specialized agent tasks, background watchers, and multi-agent workflows.
- **CI/CD & DevOps Synergy:** Integrating Claude Code into Git branching strategies, PR creation, and automated local testing pipelines.
