# Claude Spectra 🌌

A comprehensive collection of architecture briefs, prompts, and implementation guides for building autonomous, specialized AI agents using Anthropic's Claude. 

This repository serves as a knowledge base and blueprint for developing multi-agent systems, integrating Claude with various APIs, and automating complex workflows.

## 📂 Contents

The `guides/` directory contains detailed briefs for a wide variety of agentic use cases:

- **Business & Marketing Automation**: Email attachments to Google Drive, Instagram marketing agents, Lead intake swarms.
- **Development & DevOps**: Custom web product development guides, ERPNext integrations, API developer assistants.
- **Media & Content Creation**: Video pipeline operators (Higgsfield/FFmpeg), YouTube shorts automation.
- **System Orchestration**: Multi-session console architectures, Google Sheets autofill integrations.
- **Agentic Coaching**: Agentic development and Windows coaching setups.

## 🎯 Purpose

These guides are intended to standardize the process of setting up role-specific AI agents. Each brief includes context, responsibilities, API integration requirements, and step-by-step reasoning prompts necessary for Claude to function autonomously within a specific domain.

## 🚀 Getting Started

Browse the `guides/` folder to find the architectural brief that fits your project. You can inject these markdown briefs directly into your System Prompts or use them as foundational instructions for Claude-powered applications.
